# planificacion_viajes
Creamos un pequeño frontal en el que el usuario puede introducir el país o ciudad que quiere conocer y el número de días que dispone para realizar un viaje, y a través de Agentes SDK (IA Generativa) se crea una planificación del viaje para el lugar y duración elegidos.

Necesitarás un documento .env en el que incluyas la siguiente línea: 
ANTHROPIC_API_KEY="tu_clave_api_de_anthropic_aqui"
